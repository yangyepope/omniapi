# 流量管理与重放攻击测试系统 - 数据模型设计

**版本**: v1.0
**日期**: 2026-03-28
**数据库**: PostgreSQL 14+

---

## 设计原则

1. **简单优先**: 不分区、不分表
2. **级联删除**: 服务删除时级联删除所有子资源
3. **冗余字段**: 关键统计字段冗余存储，减少 JOIN
4. **JSONB 灵活存储**: 变体转换、规则配置等使用 JSONB

---

## 表结构详解

### 1. services (服务表)

**说明**: 服务列表页的核心数据，服务名本身作为主键

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | 服务名，如 "order-service" |
| description | TEXT | 服务描述 |
| owner | VARCHAR(128) | 责任人 |
| created_at | TIMESTAMP | 创建时间 |
| last_active_at | TIMESTAMP | 最近一次流量捕获时间 |
| total_flows | INTEGER | 原始流量总数（冗余） |
| unique_flows | INTEGER | 筛选流量总数（冗余） |
| interface_count | INTEGER | 接口数量（冗余） |

**索引**:
- `idx_services_active`: last_active_at DESC
- `idx_services_owner`: owner

---

### 2. interfaces (接口表)

**说明**: 挂载在服务下，记录接口定义和统计

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | UUID |
| service_id | VARCHAR(64) FK | 所属服务，ON DELETE CASCADE |
| normalized_path | VARCHAR(2048) | 去重用归一化路径（忽略Query） |
| display_path_template | VARCHAR(2048) | 展示用路径模板（保留Query结构） |
| method | VARCHAR(10) | GET/POST/PUT/DELETE等 |
| status | VARCHAR(20) | auto-complete/document/deprecated |
| created_at | TIMESTAMP | 创建时间 |
| last_request_at | TIMESTAMP | 最近一次请求时间 |
| deprecated_at | TIMESTAMP | 标记废弃时间 |
| total_requests | INTEGER | 原始流量统计（冗余） |
| unique_flows | INTEGER | 筛选流量统计（冗余） |
| variant_count | INTEGER | 变体数量（冗余） |
| replay_count | INTEGER | 重放次数（冗余） |

**约束**:
- UNIQUE(service_id, normalized_path, method)

**索引**:
- `idx_interfaces_service`: service_id
- `idx_interfaces_status`: status
- `idx_interfaces_active`: last_request_at DESC
- `idx_interfaces_deprecated`: deprecated_at WHERE status='deprecated'

---

### 3. interface_query_params (接口Query参数表)

**说明**: 记录接口Query参数的元数据（变量/常量）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 自增ID |
| interface_id | VARCHAR(64) FK | 所属接口，ON DELETE CASCADE |
| param_name | VARCHAR(128) | 参数名 |
| param_type | VARCHAR(20) | variable/constant |
| sample_values | JSONB | 样本值数组 |

**约束**:
- UNIQUE(interface_id, param_name)

---

### 4. raw_flows (原始流量表)

**说明**: 临时存储，TTL清理

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | UUID |
| service_id | VARCHAR(64) | 冗余存储 |
| captured_at | TIMESTAMP | 捕获时间 |
| method | VARCHAR(10) | 请求方法 |
| url | TEXT | 完整URL |
| headers | JSONB | 请求头 |
| body | BYTEA | 请求体（二进制） |
| body_size | INTEGER | Body大小 |
| client_ip | INET | 客户端IP |
| parsed | BOOLEAN | 是否已解析 |
| deduped | BOOLEAN | 是否已去重 |
| dedup_key | VARCHAR(32) | MD5哈希（调试） |
| created_at | TIMESTAMP | 入库时间 |
| expire_at | TIMESTAMP | 过期时间（用于清理） |

**索引**:
- `idx_raw_flows_service`: service_id
- `idx_raw_flows_captured`: captured_at DESC
- `idx_raw_flows_expire`: expire_at WHERE expire_at IS NOT NULL
- `idx_raw_flows_dedup`: dedup_key
- `idx_raw_flows_parsed`: parsed WHERE parsed = FALSE

---

### 5. filtered_flows (筛选流量表)

**说明**: 去重后的永久存储，挂载到接口下

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | UUID |
| interface_id | VARCHAR(64) FK | 所属接口，ON DELETE CASCADE |
| raw_flow_id | VARCHAR(64) | 来源原始流量ID（可选） |
| captured_at | TIMESTAMP | 捕获时间 |
| method | VARCHAR(10) | 请求方法 |
| original_path | TEXT | 原始完整路径（含Query） |
| headers | JSONB | 请求头 |
| body | BYTEA | 请求体 |
| body_size | INTEGER | Body大小 |
| client_ip | INET | 客户端IP |
| dedup_key | VARCHAR(32) | 去重键（调试） |
| created_at | TIMESTAMP | 创建时间 |
| variant_count | INTEGER | 变体数量（冗余） |
| replay_count | INTEGER | 重放次数（冗余） |

**索引**:
- `idx_filtered_flows_interface`: interface_id
- `idx_filtered_flows_captured`: captured_at DESC
- `idx_filtered_flows_body_size`: body_size
- `idx_filtered_flows_body_search`: GIN(to_tsvector) 全文搜索

---

### 6. flow_tags (流量标签表)

**说明**: 流量与标签的多对多关系

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 自增ID |
| flow_id | VARCHAR(64) FK | 所属流量，ON DELETE CASCADE |
| tag | VARCHAR(64) | 标签名 |
| created_at | TIMESTAMP | 创建时间 |

**约束**:
- UNIQUE(flow_id, tag)

**索引**:
- `idx_flow_tags_flow`: flow_id
- `idx_flow_tags_tag`: tag
- `idx_flow_tags_search`: tag, flow_id

---

### 7. variants (变体表)

**说明**: 支持Fork的多级变体

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | UUID |
| source_type | VARCHAR(20) | 'flow' 或 'variant' |
| source_id | VARCHAR(64) | 父级ID |
| root_flow_id | VARCHAR(64) FK | 根流量ID，ON DELETE CASCADE |
| fork_chain | JSONB | Fork链ID数组 |
| name | VARCHAR(256) | 变体名称 |
| description | TEXT | 描述 |
| transformations | JSONB | 修改记录数组 |
| method | VARCHAR(10) | 最终请求方法 |
| url | TEXT | 最终URL |
| headers | JSONB | 最终请求头 |
| body | BYTEA | 最终请求体 |
| replay_count | INTEGER | 重放次数 |
| created_at | TIMESTAMP | 创建时间 |

**索引**:
- `idx_variants_source`: source_type, source_id
- `idx_variants_root`: root_flow_id
- `idx_variants_created`: created_at DESC

---

### 8. replay_tasks (重放任务表)

**说明**: 重放任务管理

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | UUID |
| name | VARCHAR(256) | 任务名称 |
| task_type | VARCHAR(20) | single/batch/proportional/sequential |
| target_url | TEXT | 目标地址 |
| concurrency | INTEGER | 并发数，默认10 |
| interval_ms | INTEGER | 请求间隔，默认0 |
| timeout_ms | INTEGER | 超时时间，默认30000 |
| source_config | JSONB | 任务内容配置 |
| status | VARCHAR(20) | pending/running/completed/failed/cancelled |
| total_count | INTEGER | 总数量 |
| completed_count | INTEGER | 已完成数量 |
| failed_count | INTEGER | 失败数量 |
| created_at | TIMESTAMP | 创建时间 |
| started_at | TIMESTAMP | 开始时间 |
| completed_at | TIMESTAMP | 完成时间 |
| error_message | TEXT | 错误信息 |

**索引**:
- `idx_replay_tasks_status`: status
- `idx_replay_tasks_created`: created_at DESC

---

### 9. replay_results (重放结果表)

**说明**: 单次重放执行结果

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(64) PK | UUID |
| task_id | VARCHAR(64) FK | 所属任务，ON DELETE CASCADE |
| source_type | VARCHAR(20) | 'flow' 或 'variant' |
| source_id | VARCHAR(64) | 流量或变体ID |
| status | VARCHAR(20) | success/failed/timeout |
| request_method | VARCHAR(10) | 实际请求方法 |
| request_url | TEXT | 实际请求URL |
| request_headers | JSONB | 实际请求头 |
| request_body | BYTEA | 实际请求体 |
| response_status | INTEGER | 响应状态码 |
| response_headers | JSONB | 响应头 |
| response_body | BYTEA | 响应体（限制1MB） |
| response_size | INTEGER | 响应大小 |
| latency_ms | INTEGER | 执行耗时 |
| executed_at | TIMESTAMP | 执行时间 |
| error_message | TEXT | 错误信息 |

**索引**:
- `idx_replay_results_task`: task_id
- `idx_replay_results_source`: source_type, source_id
- `idx_replay_results_status`: status
- `idx_replay_results_executed`: executed_at DESC

---

### 10. normalization_rules (归一化规则表)

**说明**: 路径归一化规则配置

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 自增ID |
| name | VARCHAR(128) | 规则名称 |
| rule_type | VARCHAR(20) | builtin/custom |
| pattern | VARCHAR(512) | 正则表达式 |
| replacement | VARCHAR(128) | 替换值，如 "{id}" |
| priority | INTEGER | 优先级（数字越小越高） |
| enabled | BOOLEAN | 是否启用 |
| deletable | BOOLEAN | 是否可删除 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

**索引**:
- `idx_norm_rules_priority`: priority
- `idx_norm_rules_enabled`: enabled

---

### 11. system_configs (系统配置表)

**说明**: 系统全局配置

| 字段 | 类型 | 说明 |
|------|------|------|
| id | SERIAL PK | 自增ID |
| config_key | VARCHAR(128) UNIQUE | 配置键 |
| config_value | TEXT | 配置值 |
| value_type | VARCHAR(20) | string/int/bool/json |
| description | TEXT | 描述 |
| updated_at | TIMESTAMP | 更新时间 |
| updated_by | VARCHAR(128) | 更新者 |

---

### 12. operation_logs (操作日志表)

**说明**: 用户操作审计日志

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL PK | 自增ID |
| operation_type | VARCHAR(64) | 操作类型 |
| target_type | VARCHAR(64) | 目标类型 |
| target_id | VARCHAR(64) | 目标ID |
| request_data | JSONB | 请求参数 |
| response_data | JSONB | 响应结果 |
| success | BOOLEAN | 是否成功 |
| error_message | TEXT | 错误信息 |
| operator | VARCHAR(128) | 操作者 |
| client_ip | INET | 客户端IP |
| user_agent | TEXT | 用户代理 |
| created_at | TIMESTAMP | 创建时间 |

**索引**:
- `idx_op_logs_type`: operation_type
- `idx_op_logs_target`: target_type, target_id
- `idx_op_logs_created`: created_at DESC

---

## 级联删除关系

| 父表 | 子表 | 删除行为 |
|------|------|----------|
| services | interfaces | CASCADE |
| interfaces | interface_query_params | CASCADE |
| interfaces | filtered_flows | CASCADE |
| filtered_flows | flow_tags | CASCADE |
| filtered_flows | variants | CASCADE (通过 root_flow_id) |
| replay_tasks | replay_results | CASCADE |

---

## 数据保留策略

| 表 | 保留策略 | 清理方式 |
|----|----------|----------|
| raw_flows | 3-7天自动清理 | 物理删除 |
| filtered_flows | 永久保留 | 手动删除，级联删除变体 |
| variants | 永久保留 | 随筛选流量级联删除 |
| replay_results | 永久保留 | 随任务级联删除 |
| operation_logs | 90天 | 物理删除 |
