## 1. 项目概述

### 1.1 系统名称
流量管理与重放攻击测试系统

### 1.2 系统定位
内部工具后台管理系统，用于捕获、管理微服务流量，并提供重放攻击测试能力，支持安全团队进行安全测试。

### 1.3 目标用户
- **安全团队**（唯一用户群体）
- 无需角色划分

### 1.4 页面层级结构
```
服务列表（一级页面）
  └── 接口列表（二级页面，挂载在服务下）
        └── 流量列表（三级页面，挂载在接口下）
              └── 流量详情（变体管理、重放执行）

全局流量搜索（独立页面，跨服务/接口）
```

## 2. 功能需求

### 2.1 流量接入层

#### 2.1.1 数据来源
- 通过 Nginx mirror 机制获取流量
- 仅捕获请求数据，不存储响应数据

#### 2.1.2 捕获范围
- **服务数量**: 10+ 个微服务
- **协议类型**: REST API
- **环境**: 开发环境
- **数据大小**: 单请求 body 最大 10MB

#### 2.1.3 捕获字段
| 字段 | 说明 |
|------|------|
| 时间戳 | 精确到毫秒 |
| 服务名称 | 从 URL 第一层路径提取 |
| 接口路径 | URL Path，保留完整路径 |
| 请求方法 | GET/POST/PUT/DELETE 等 |
| 请求头 | Headers |
| 请求体 | Body |
| 客户端 IP | - |

#### 2.1.4 数据处理流程
```
Nginx Mirror 流量
    ↓
[流量接收 API] → 限流保护 → 流量解析
    ↓
[原始流量表] （临时存储，3-7天自动清理）
    ↓
异步队列 (Celery + Redis)
    ↓
[去重处理模块]
    · 请求头过滤（排除时间/Cookie/Token）
    · Body 字段过滤（排除动态字段）
    · 去重键生成（MD5）
    ↓
[筛选流量表]（永久保留，挂载到对应接口）
    ↓
服务发现 → 接口发现（路径归一化）
```

#### 2.1.5 限流保护
- **策略**: 基于 IP 的限流
- **阈值**: 单 IP 100 req/s（可配置）
- **响应**: HTTP 429 + 错误信息

#### 2.1.6 去重策略

**去重字段**（5个参与计算）：
| 字段 | 处理方式 |
|------|----------|
| 服务名称 | 从 URL 第一层提取 |
| 接口路径 | 归一化后的路径（忽略 Query） |
| 请求方法 | 原值 |
| 请求头 | 排除时间、Cookie、Token 相关字段 |
| 请求体 | 排除配置的动态字段（如 timestamp、nonce） |

**去重规则**:
- 以上五个字段完全相同的请求视为重复
- 仅保留首次捕获的请求
- 去重算法: MD5 哈希
- 处理方式: 异步（Celery + Redis）

**请求头排除字段**:
```
时间相关: Date, X-Request-Time, X-Timestamp 等
Cookie: Cookie, Set-Cookie
Token: Authorization, X-Auth-Token, X-Token 等
```

**Body 动态字段排除**（全局配置）:
```
timestamp, nonce, random, _t, callback, sign
```

### 2.2 资产管理核心层

#### 2.2.1 服务管理模块（一级页面）

**页面功能**:
- 服务列表展示
- 服务 CRUD
- 服务责任人标记（页面直接编辑）
- 服务统计展示

**服务发现子模块**:
- URL 解析与服务名提取（URL 第一层路径）
- 服务自动创建

**服务统计字段**:
| 字段 | 说明 |
|------|------|
| 总流量数 | 原始流量计数 |
| 唯一流量数 | 筛选流量计数 |
| 接口数量 | 该服务下的接口数 |
| 最后活跃时间 | 最近一次流量捕获时间 |

**服务删除**:
- **级联删除**: 删除服务时，级联删除该服务下的所有接口、流量、变体、重放记录
- **确认机制**: 删除前展示"将删除 X 个接口、Y 条流量、Z 个变体"的确认弹窗

#### 2.2.2 接口管理模块（二级页面，挂载在服务下）

**页面入口**: 从服务列表页点击进入

**页面功能**:
- 接口列表展示
- 接口 CRUD
- 接口状态管理
- 接口导入（JSON）
- 接口统计展示
- 无流量接口检测

**接口发现子模块**:

*路径归一化引擎*:
- **策略**: 混合策略
  - 内置规则匹配（数字 ID、UUID、MD5、短 Token、日期等）
  - 自定义规则配置（管理员设置）
  - 未知路径标记（待人工确认）
- **双重处理**:
  - 去重时: 忽略 Query，仅归一化 Path
  - 展示时: 保留 Query 结构，`/api/search?q={query}&page={page}`

*Query 参数分析*:
- 自动识别变量参数（基于样本统计）
- 支持手动标记参数类型（变量/常量）

**接口状态流转**（单向不可反转）:
```
Auto-Complete（自动发现）
      ↓（手动标记或 JSON 导入）
Document（文档确认）
      ↓（30天无流量自动标记或手动标记）
Deprecated（废弃）
      ↓（手动删除）
[删除]
```

**接口统计字段**:
| 字段 | 说明 |
|------|------|
| 总请求数 | 原始流量统计 |
| 去重后流量数 | 筛选流量统计 |
| 最后请求时间 | - |
| 变体流量数量 | - |
| 重放次数 | - |

**无流量接口检测**:
- 检测周期: 每天
- 判定条件: 30天内无流量
- 处理方式: 自动标记为 Deprecated

### 2.3 流量管理模块

#### 2.3.1 数据分层

| 数据层级 | 存储内容 | 保留策略 | 清理方式 |
|----------|----------|----------|----------|
| 原始流量 | 接收的所有请求（含重复） | 3-7天自动清理 | 物理删除 |
| 筛选流量 | 去重后的唯一请求 | 永久保留，可手动删除 | 物理删除，级联删除变体 |
| 变体流量 | 重放时修改生成的请求 | 永久保留，随筛选流量级联删除 | 物理删除 |

| 请求方法 | - |
| Body 大小 | - |
| Body 预览 | 前 200 字符 |
| 标签 | - |

**操作**:

### 2.4 变体管理模块（挂载在流量下）

#### 2.4.1 变体概念
- 基于筛选流量通过修改生成的请求
- 用于重放测试
- 永久保留

#### 2.4.2 变体生成

**修改方式**（按顺序叠加执行）:

| 顺序 | 方式 | 说明 |
|------|------|------|
| 1 | 模板变量替换 | `${timestamp}`, `${randomId}`, `${uuid}` 等 |
| 2 | 字段级修改 | 指定 JSON 字段路径修改值 |
| 3 | 脚本转换 | Python/JS 语法（沙箱执行） |
| 4 | 手动编辑 | 弹出编辑器人工修改 |

**变体 Fork 机制**:
- 支持基于变体创建变体（多级变体）
- 记录 Fork 链: `[root_flow_id, variant_a_id, variant_b_id]`
- 展示变体层级关系

#### 2.4.3 变体存储
- 存储完整的修改后请求数据（非修改规则）
- 归属到原始流量所在的接口下
- 随原始筛选流量级联删除

### 2.5 重放执行层

#### 2.5.1 重放目标
- 用于安全测试，验证系统安全性
- 支持切换到不同环境（目标地址可配置）

#### 2.5.2 重放模式

| 模式 | 说明 |
|------|------|
| 单条重放 | 选择单条流量/变体进行重放 |
| 批量重放 | 选择多条流量批量执行 |
| 按比例重放 | 按设定比例抽样重放 |
| 按时间重放 | 按捕获时间顺序重放 |

#### 2.5.3 重放配置

| 配置项 | 说明 |
|--------|------|
| 目标地址 | 可配置重放的目标地址 |
| 并发控制 | 可设置并发数限制（默认 10） |
| 请求间隔 | 可设置请求间隔时间 |
| 超时设置 | 可设置请求超时时间（默认 30s） |

#### 2.5.4 执行引擎

**并发控制**:
- 支持设置并发数（1-100）
- 支持设置请求间隔（毫秒级）

**断路器机制**:
- 连续失败超过阈值（10 次/1分钟）自动暂停
- 发送告警通知

**结果记录**:
| 字段 | 说明 |
|------|------|
| 响应状态码 | - |
| 响应头 | - |
| 响应体 | 限制大小 1MB |
| 执行时间 | 毫秒 |
| 是否成功 | - |
| 重放时间戳 | - |
| 错误信息 | 如有 |
| 关联变体流量 | 记录是对哪个变体/原始流量的重放 |

#### 2.5.5 结果查看
- 重放历史列表
- 单条重放详情
- 成功率统计
- 平均响应时间统计
- 按变体流量查看重放结果

#### 2.5.6 结果对比（待定）
- 与原响应对比状态码一致性

#### 2.5.7 定时重放（待定，简化设计）

**触发粒度**:
- 仅支持单接口 + 筛选条件
- 不支持多接口组合

**配置**:
```
- Cron 表达式
- 目标接口
- 流量筛选条件（标签、数量限制）
```

## 3. 非功能需求

### 3.1 性能需求
- 流量接收延迟: P99 < 50ms
- 去重处理延迟: P99 < 5s
- 列表页加载时间: P99 < 2s
- 全文搜索响应: P99 < 3s

### 3.2 可用性需求
- 内部工具，无需高可用部署
- 支持单机部署

### 3.3 安全需求
- 内部网络使用，无需复杂认证
- 不涉及敏感数据脱敏（已确认无敏感数据）

### 3.4 技术实现
- **后端框架**: FastAPI + Pydantic
- **数据库**: PostgreSQL
- **前端**: Vue
- **异步处理**: Celery + Redis
- **去重算法**: MD5

## 5. 术语表

| 术语 | 说明 |
|------|------|
| 流量 | 指 HTTP 请求数据 |
| 原始流量 | 从 Nginx mirror 接收的所有请求（含重复） |
| 筛选流量 | 经过去重处理后保留的唯一请求 |
| 变体流量 | 基于筛选流量通过修改生成的请求，用于重放测试 |
| 变体 Fork | 基于已有变体创建新的变体（多级变体） |
| 重放 | 将捕获的请求重新发送到目标服务 |
| 去重 | 根据指定字段判断是否重复，仅保留一条 |
| 归一化路径 | 将路径中的变量部分替换为占位符（如 `/users/123` → `/users/{id}`） |
| 服务 | 微服务名称，从 URL 第一层路径提取 |
| 接口 | 唯一的 Path + Method 组合 |
