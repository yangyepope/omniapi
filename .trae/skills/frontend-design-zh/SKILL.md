此技能指导你创建独特的、生产级的前端界面，拒绝平庸的“AI 生成感”审美，并在前后端分离架构中保持严格的契约一致性。

当用户提供前端需求（构建组件、页面、应用）或后端模型更新时，你应当综合运用以下能力：

## 核心自动化技能（契约同步）

当你正在处理全栈或前后端联调任务时，必须自动应用以下三个核心自动化技能：

### 1. Sync-Schema (自动类型同步)
**触发时机**：当你看到后端模型（如 FastAPI/Pydantic/SQLModel）发生更新时。
**执行动作**：自动更新前端 `frontend/src/types`（或对应的生成目录）下相关的 TypeScript Interface。确保前端的类型定义始终与后端数据结构保持绝对一致。

### 2. CRUD-Generator (钩子生成器)
**触发时机**：根据后端的 FastAPI Router 定义新增或修改接口时。
**执行动作**：在前端 `src/hooks`（或对应目录）下生成对应的基于 React Query (TanStack Query) 的 `useQuery`（用于查询）或 `useMutation`（用于变更）钩子。必须包含正确的泛型类型推导和错误处理。

### 3. Zod-Validator (表单校验同步)
**触发时机**：前端需要处理用户输入并提交给后端特定接口时。
**执行动作**：为前端表单生成与后端 Pydantic 定义完全匹配的 Zod 校验 Schema（`z.object({...})`）。确保前端在提交请求前，能在客户端进行与后端规则完全一致的拦截与验证。

## 前端设计与美学指南 (Design Thinking)

在编写 UI 代码之前，理解上下文并确定一个**大胆的**美学方向：
- **目的**：这个界面解决什么问题？谁在使用它？
- **基调**：选择一种极致的风格：极简主义、复古未来主义、自然有机、奢华精致、趣味玩具感、杂志编辑风、粗野主义、装饰艺术等。以此为灵感，设计出符合方向的界面。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：是什么让它令人难忘？

**关键要求**：选择明确的概念方向并精准执行。无论是极致的繁复还是克制的极简，关键在于“有意为之”的设计感。

### 具体审美准则：
- **排版 (Typography)**：选择美观、独特、有趣的字体。避免使用烂大街的字体（如 Arial, Inter），选择有辨识度的展示字体搭配优雅的正文字体。
- **色彩与主题 (Color & Theme)**：坚持统一的美学风格。使用 CSS 变量保持一致性。强烈的单色搭配锐利的强调色，通常优于平庸且平均分布的调色板。
- **动效 (Motion)**：使用动画增强微交互。在 React 中优先使用 Motion 库或 Tailwind CSS 动画。关注高影响力的瞬间：一个精心编排的页面加载交错展现（staggered reveals），比到处散落的杂乱动效更令人愉悦。
- **空间构图 (Spatial Composition)**：打破常规的布局。尝试不对称、元素重叠、对角线流动、打破网格的元素。使用大面积留白或克制的高密度排版。
- **背景与细节 (Backgrounds & Details)**：创造氛围和深度，而不是默认使用纯色背景。添加纹理、噪点、渐变网格、几何图案、透明图层叠加、光影效果等。

**禁止事项**：
永远不要使用毫无新意的“AI 默认审美”：泛滥的紫色渐变白底、可预测的死板布局、缺乏上下文个性的饼印式设计。

**执行标准**：
将代码的复杂度与你的审美愿景相匹配。繁复的设计需要细致的动效和特效代码；极简的设计则需要极度的克制，对间距、排版和微小细节的精准把控。优雅来源于完美的执行。
