# 顶栏面包屑与全局导航重构日志

**操作时间**: [2026-03-30 05:20:00]
**操作主题**: 将顶部导航替换为面包屑样式，并优化全局搜索与通知区域

## 1. 任务背景
为了提升后台管理的专业感，并将全局布局对齐最新的“企业级浅色设计”。原有的顶栏列表式导航被替换为更加灵活的路径面包屑（Dashboard > ...），同时对搜索框、通知图标和用户区域进行了视觉升级。

## 2. 具体改动详情

### 2.1 侧边栏 (Sidebar) 强化
- **Logo 迁入**: 由于顶栏左侧预留给面包屑，原顶栏的“流量大师” Logo 及其副标题已成功迁移至 `Sidebar.tsx` 的顶部。
- **布局调整**: 将 Sidebar 的固定高度从 `top-16` 修改为 `top-0`（通顶布局），使侧边栏在视觉上成为页面的独立支撑轴。

### 2.2 顶栏 (Header) 彻底重构
- **动态面包屑**: 
  - 引入 `useRouterState` 实时监听 URL。
  - 实现了动态路径映射。当前支持 `仪表面板`、`服务管理`、`用户设置`、`项目管理` 和 `系统管理` 的动态显示。
  - 样式对齐：根节点灰色文字 -> 分隔符 -> 蓝色加粗激活态文字。
- **搜索框升级**: 替换为全圆角浅灰色背景框，使用了更符合语境的占位符“搜索资源或指标...”。
- **右侧操作区**:
  - 精简了通知图标样式，并固定了红点告警位置。
  - 增加了垂直分割线，将通知区与用户信息区进行物理分割。
  - 优化了用户头像与登录名称的排版，补充了实时的 `Administrator` 角色说明标签。

### 2.3 布局 (Layout) 联动
- 将 Header 的定位修改为 `left-64`，使其与通顶的 Sidebar 完美侧接，避免了视觉上的重叠。

- [x] 在服务页（/services）显示为 `首页 > 服务管理`。
- [x] 搜索框聚焦样式正常，无蓝边溢出。
- [x] 退出登录按钮依然能在新布局中正常工作。
