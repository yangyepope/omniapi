# 组件拆分与结构优化实施方案

## 任务背景
在项目当前状态下，`DashboardDesign.tsx` 和 `theme-provider.tsx` 这两个核心文件零散地放置在 `frontend/src/components/` 根目录中。为了遵守现代 React 项目最佳实践并保持目录结构清晰，我们需要将它们提取到专门的组件目录中。

## 计划变更内容 (Proposed Changes)

### 1. 拆分仪表盘组件 (Dashboard Component)
由于 `DashboardDesign.tsx` 体积较大且包含多个内部组件，新建 `components/Dashboard/` 文件夹进行集中管理：
- **[新建]** `frontend/src/components/Dashboard/StatCard.tsx`：用于顶部数字统计卡片。
- **[新建]** `frontend/src/components/Dashboard/ProgressBar.tsx`：用于进度条 UI。
- **[重构]** `frontend/src/components/Dashboard/index.tsx`：作为主容器，导入上述拆分后的组件。

### 2. 重构主题提供者 (Theme Provider)
全局提供者组件应当被统一管理。新建 `components/providers/` 文件夹：
- **[移动]** 将 `components/theme-provider.tsx` 移至 `components/providers/theme-provider.tsx`。
- **[修改]** 更新所有引用到此文件的导入路径（例如项目主入口及相关路由节点），保证项目正常编译。

## 验证计划 (Verification Plan)
- **静态检查**：检查所有引用路径，确认 TypeScript 没有报错。
- **本地运行验证**：确认浏览器内前端页面无缝渲染，无丢失组件。
