# 2026-04-05 修复侧滑详情页被全局 Header 遮挡的问题

## 现象 (Symptom)
在“流量详情”页面打开变体侧滑层时，侧滑层的顶部（包括标题和关闭按钮）被系统的全局导航栏（Logo/搜索框/头像区域）遮挡了。
- **视觉冲突**: 导航栏的 `blur` 背景覆盖在侧滑层文字之上，导致无法点击关闭按钮或查看标题。

## 调查 (Investigation)
1. **开发者工具分析**: 
   - 全局 Header 的 `z-index` 为 `z-50`。
   - 侧滑层的 `z-index` 为 `z-[120]`。
   - 侧滑层嵌套在 `<main>` 标签内。
2. **根因定位**: 
   - `_layout.tsx` 中的 `<main>` 标签定义了 `relative z-0`。
   - 这在 `main` 容器上创建了一个新的**层叠上下文 (Stacking Context)**。
   - 即使内部子元素 `z-index` 为 120，它也仅在 `main` 内部生效，无法超越同级的 `Header (z-50)`。

## 修复 (The Fix)
### 布局调整 (Frontend)
- 修改 `frontend/src/routes/_layout.tsx`：移除 `main` 标签上的 `z-0` 类。
- **效果**: 移除 `z-0` 后，`main` 不再强制创建独立的层叠上下文（除非有 transform 等其他属性），内部的 `fixed` 元素（侧滑层）将直接相对于全局视口及 `z-index` 进行竞争。
- **结果**: `z-[120]` 成功覆盖 `z-50`，侧滑层现在完整显示在最前端。

## 验证 (Proof)
1. 打开侧滑层，确认标题和关闭按钮不再被搜索栏区域遮挡。
2. 确认搜索栏能够被侧滑层的背景遮罩（Backdrop）覆盖，防止在侧滑层打开时误点导航项。
