# 2026-04-05 优化差异视图 (DIFF) 的语义识别与 UI 表现

## 现象 (Symptom)
在变体详情侧滑页的“差异对比 (DIFF)”模式下：
1. **统计失效**: 当变体重放发生网络错误（如 `CONNECTION_ERROR`）时，统计条显示“0 CHANGES FOUND”，因为错误文本无法作为 JSON 进行 Path 对比。
2. **视觉单薄**: 无论重放成功还是失败，对比界面的色调保持一致，缺乏对异常状态的感官警示。
3. **内容留白**: 布局分布不均，底部存在大量无效留白。

## 调查 (Investigation)
- **引擎局限**: `DiffCodeViewer` 固定使用 `JSON.parse` 驱动的 diff 算法。一旦解析失败（网络错误字符串），算法返回空列表。
- **状态感知不足**: 界面没有根据 `last_response_code` 或响应内容特征调整渲染主题。

## 根因 (Root Cause)
- **硬编码解析**: 差异引擎默认所有响应均为合法 JSON。
- **UI 状态机缺失**: 未定义“网络故障对比”这一特殊业务场景的 UI 分支。

## 修复 (The Fix)
### 1. 语义化差异引擎 (Semantic Engine)
- **特征识别**: 增加对 `CONNECTION_ERROR` 和 `TIMEOUT_ERROR` 特征字符串的检测。
- **状态化统计**: 
    - 检测到网络错误时，统计栏标签从数字对比切换为 **“NETWORK_FAILURE”**。
    - 状态灯同步变为呼吸红色。
- **对比模式自动降级**: 当无法进行 JSON Path 对比时，自动显示“手动诊断模式”提示，告知用户引擎已自动跳过递归对比。

### 2. 视觉进化 (UI Evolution)
- **警告色渗透**: 网络故障时，右侧对比区（Variant Response）背景色微调为 `red-500/[0.02]`，并增加 `ring-2` 边框高亮。
- **精致化控件**: 
    - 重新设计了 Stats Bar，引入了渐变背景和更丰富的 Lucide 图标。
    - 差异路径详情卡片增加了内阴影和更好的边距控制。
    - 全面提升字号（10px -> 12px/14px），确保信息密度平衡且易读。

## 验证 (Proof)
1. **故障场景**: 触发一个无法连接的重放，进入 DIFF 模式。统计条准确显示红色“CONNECT ERROR”，右侧面板显示红色 OFFILINE 标识。
2. **成功场景**: 修改变体 Body 使其与原始值不同，重放成功后进入 DIFF。确认 JSON Path 审计列表恢复正常，且显示“X CHANGES FOUND”。
