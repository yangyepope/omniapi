# 执行计划 (Executing Plans)

## 概览

加载计划，进行批判性审查，执行所有任务，完成后报告。

**开始时宣布：** “我正在使用 executing-plans 技能来执行此计划。”

**注意：** 告诉你的类比伙伴（Human Partner），超级能力（Superpowers）如果能访问子代理，效果会更好。如果在具备子代理支持的平台（如 Claude Code 或 Codex）上运行，其工作质量将显著提高。如果子代理可用，请使用 superpowers:subagent-driven-development 代替此技能。

## 流程

### 步骤 1：加载并审查计划
1. 读取计划文件
2. 进行批判性审查 —— 确定对计划的任何疑问或担忧
3. 如果有疑问：在开始之前向你的类比伙伴提出
4. 如果没有疑问：创建 TodoWrite 并继续

### 步骤 2：执行任务

对于每个任务：
1. 标记为 in_progress（运行中）
2. 严格遵循每一个步骤（计划包含微任务步骤）
3. 按规定运行验证
4. 标记为已完成 (completed)

### 步骤 3：完成开发

所有任务完成后并验证通过后：
- 宣布： “我正在使用 finishing-a-development-branch 技能来完成这项工作。”
- **要求子技能：** 使用 superpowers:finishing-a-development-branch
- 遵循该技能来验证测试、呈现选项、执行选择

## 何时停止并请求帮助

**在以下情况下立即停止执行：**
- 遇到阻塞（缺失依赖、测试失败、指令不明确）
- 计划存在严重缺陷，导致无法启动
- 你不理解某项指令
- 验证多次失败

**请请求澄清，而不是猜测。**

## 何时重新审视先前步骤

**在以下情况下返回审查（步骤 1）：**
- 伙伴根据你的反馈更新了计划
- 基本方案需要重新思考

**不要强行通过阻塞点** —— 停止并请求帮助。

## 牢记

- 首先进行计划的批判性审查
- 严格遵循计划步骤
- 不要跳过验证
- 在计划要求时引用技能
- 遇到阻塞时停止，不要猜测
- 未经用户明确同意，严禁在 main/master 分支上开始实现

## 集成

**要求的工作流技能：**
- **superpowers:using-git-worktrees** —— 要求：在开始之前设置隔离的工作区
- **superpowers:writing-plans** —— 创建此技能执行的计划
- **superpowers:finishing-a-development-branch** —— 所有任务完成后完成开发
