# 技能设计中的说服原则 (Persuasion Principles)

## 概览

大语言模型（LLM）对与人类相同的说服原则会产生反应。理解这些心理学原理有助于你设计出更有效的技能 —— 目的不是操纵，而是确保关键实践即使在压力之下也能被遵循。

**研究基础：** Meincke 等人 (2025) 在 28,000 次 AI 对话中测试了 7 种说服原则。结果显示，说服技术使合规率提高了一倍以上（从 33% 提升至 72%，p < .001）。

## 七大原则

### 1. 权威 (Authority)
**定义：** 对专业知识、资历或官方来源的遵从。

**在技能中如何运作：**
- 使用命令式语言： “你必须”、“严禁”、“始终”。
- 不可逾越的框架： “无例外”。
- 消除决策疲劳和找借口的机会。

**何时使用：**
- 强制执行纪律的技能（TDD、验证要求）。
- 关乎安全的关键实践。
- 既定的最佳实践。

**示例：**
```markdown
✅ 先写代码后写测试？删掉它。重新开始。绝无例外。
❌ 在可行的情况下，考虑先写测试。
```

### 2. 承诺 (Commitment)
**定义：** 与之前的行为、陈述或公开声明保持一致。

**在技能中如何运作：**
- 要求宣布： “宣布正在使用的技能”。
- 强制进行明确选择： “选择 A, B 或 C”。
- 使用跟踪工具： 为了核对清单而使用的 TodoWrite。

**何时使用：**
- 确保技能确实被遵循。
- 多步骤流程。
- 问责机制。

**示例：**
```markdown
✅ 当你找到一项技能时，你必须宣布： “我正使用 [技能名称]”。
❌ 考虑让你的伙伴知道你正在使用哪项技能。
```

### 3. 稀缺性 (Scarcity)
**定义：** 来源于时间限制或有限可用性的紧迫感。

**在技能中如何运作：**
- 时间绑定的要求： “在继续之前”。
- 顺序依赖性： “在 X 之后立即执行”。
- 防止拖延。

**何时使用：**
- 立即验证的要求。
- 时间敏感型工作流。
- 防止“我以后再做”。

**示例：**
```markdown
✅ 任务完成后，在继续之前立即请求代码审查。
❌ 你可以在方便的时候进行代码审查。
```

### 4. 社会证明 (Social Proof)
**定义：** 从众心理，遵循他人的做法或被认为是常态的行为。

**在技能中如何运作：**
- 通用模式： “每一次”、“总是”。
- 失败模式： “没有 Y 的 X = 失败”。
- 确立规范。

**何时使用：**
- 记录普及的实践。
- 对常见失败进行警告。
- 强化标准。

**示例：**
```markdown
✅ 没有 TodoWrite 跟踪的核对清单 = 步骤会被跳过。每一次都是如此。
❌ 有些人发现 TodoWrite 对核对清单很有帮助。
```

### 5. 统一性 (Unity)
**定义：** 共同的身份感，“我们”意识，群体归属感。

**在技能中如何运作：**
- 协作性语言： “我们的代码库”、“我们是同事”。
- 共同目标： “我们都追求质量”。

**何时使用：**
- 协作工作流。
- 建立团队文化。
- 非层级化的实践。

**示例：**
```markdown
✅ 我们是共同工作的同事。我需要你诚实的技术判断。
❌ 如果我错了，你大概应该告诉我。
```

### 6. 互惠性 (Reciprocity)
**定义：** 回报所获利益的义务感。

**如何运作：**
- 谨慎使用 —— 可能会让人觉得带有操纵性。
- 在技能文档中很少需要。

**何时避免：**
- 几乎所有情况（其他原则更有效）。

### 7. 喜爱 (Liking)
**定义：** 倾向于与我们喜欢的人合作。

**如何运作：**
- **严禁用于强制合规。**
- 与诚实反馈文化相冲突。
- 会制造谄媚行为。

**何时避免：**
- 在强制执行纪律时，始终应当避免。

## 技能类型对应的原则组合

| 技能类型 | 使用 | 避免 |
|------------|-----|-------|
| 强制执行纪律 | 权威 + 承诺 + 社会证明 | 喜爱、互惠 |
| 引导/技术型 | 适度的权威 + 统一性 | 过度的权威 |
| 协作型 | 统一性 + 承诺 | 权威、喜爱 |
| 参考型 | 仅追求清晰度 | 所有说服原则 |

## 为什么这有效：心理学依据

**清晰明确的目标降低了找借口的可能性：**
- “你必须” 消除了决策疲劳。
- 绝对化的语言排除了“这是否是一个例外？”的疑问。
- 显式的反辩解机制封堵了具体的漏洞。

**实施意图创造了自动行为：**
- 清晰的触发器 + 要求的行动 = 自动化执行。
- “当 X 时，做 Y” 比 “通常要做 Y” 更有效。
- 降低了合规过程中的认知负荷。

**LLMs 是“类人”的 (Parahuman)：**
- 在包含这些模式的人类文本上进行训练。
- 在训练数据中，权威性语言通常出现在合规行为之前。
- 承诺序列（陈述 ——> 行动）经常被建模。
- 社会证明模式（所有人都在做 X）确立了规范。

## 道德使用

**合法的：**
- 确保关键实践得到遵循。
- 创建高效的文档。
- 防止可预见的失败。

**不合法的：**
- 为了个人利益而操纵。
- 制造虚假的紧迫感。
- 基于内疚感的合规。

**测试标准：** 如果用户完全理解这项技术，它是否符合用户的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服力的七大原则。
- 影响力研究的经验基础。

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 在 28,000 次 LLM 对话中测试了 7 种原则。
- 采用说服技术后，合规率从 33% 提升至 72%。
- 权威、承诺、稀缺性最为有效。
- 验证了 LLM 行为的类人模型。

## 快速参考

在设计技能时，请自问：

1. **它属于什么类型？** （纪律类 vs. 引导类 vs. 参考类）
2. **我试图改变什么行为？**
3. **哪些原则适用？** （纪律类通常是：权威 + 承诺）
4. **我是否结合了太多原则？** （不要同时使用全部七种）
5. **这是否合乎道德？** （是否符合用户的真实利益？）
