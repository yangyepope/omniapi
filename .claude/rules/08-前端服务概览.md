# 08-前端服务概览(命令与结构)

## 技术栈
React 19 + Vite 7 + TypeScript + TanStack Router/Query + shadcn/ui + Tailwind v4 + Biome,bun 管依赖;import 统一 `@/` 别名。

## 常用命令
- 开发: `bun run dev`(http://localhost:5173)
- 检查+格式化: `bun run lint`(Biome,唯一 Lint/Format 入口)
- 重新生成 API 客户端: `bun run generate-client`(后端 Schema 变更后必跑)
- 构建: `bun run build`
- E2E: `bunx playwright test`(401 时先跑 `npx playwright test tests/auth.setup.ts`)

## 目录结构
- `src/routes`             页面路由(TanStack Router 文件式)
- `src/components/ui`      shadcn 原语(CLI 生成)
- `src/components/Common`  跨功能共享组件(DataTable/ErrorComponent/NotFound…)
- `src/components/<Feature>` 功能私有组件(services/traffic/Admin…)
- `src/client`             hey-api 生成的 API 客户端(禁手改)
- `src/lib`                cn() 等工具(format.ts 建在这)
- `src/hooks`              共享 hooks
- `src/locales`            i18n 文案(en-US / zh-CN)
