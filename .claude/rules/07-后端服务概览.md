# 07-后端服务概览(命令与结构)

## 技术栈
FastAPI + SQLModel(**同步 Session**)+ Pydantic v2 + Celery + Alembic,Python ≥3.10,uv 管依赖。

## 常用命令
- 跑测试: `bash scripts/test.sh`(coverage + pytest,production 环境自动拒跑)
- 静态检查: `bash scripts/lint.sh`(mypy + ruff check + ruff format --check)
- 新建迁移: 在容器内 `alembic revision --autogenerate -m "描述"`(迁移文件在 `app/alembic/versions/`)

## 目录结构
- `app/api/routes`  路由(接口层)
- `app/services`    业务服务层
- `app/crud.py`     数据访问
- `app/models.py`   SQLModel 模型
- `app/schemas`     Pydantic 出入参
- `app/core`        配置/DB 引擎/安全
- `app/alembic`     数据库迁移
- `app/worker.py`   Celery worker
- `tests/`          pytest(api / functional / scripts;临时脚本放 tests/scripts,功能验证放 tests/functional,禁放 backend 根或 app/)
