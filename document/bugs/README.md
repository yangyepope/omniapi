# bugs — Bug 防复发知识库索引

> 一类 bug 一份档案:「根因(架构级)+ 复发防线(tripwire)+ 关联规则」。
> 新建档案:复制 [_TEMPLATE.md](_TEMPLATE.md) 改写,命名 `BUG-{编号}-{描述}.md`。
> 与 `../changelog/FIX-*` 分工:FIX 记录**一次修复的过程**,BUG 沉淀**一类问题的防线**——互相链接,不复述。
> **每份档案必须有至少一条可执行 tripwire**;新增档案后在本索引追加一行。
> 新 bug 与已有档案同根因 → 不新建,在旧档案《复发记录》追加。
