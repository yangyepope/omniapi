# 前端实现提示词:系统画像页(服务详情 → 系统画像 Tab)

> 交给前端实现者的规格。所有请求走 `/api/v1/security/*`,鉴权 `Authorization: Bearer <JWT>`(与本控制台其余 security 接口一致)。
> 参考实现已存在:`frontend/src/security/SystemProfilePanel.tsx`(可对照)。

## 背景

「系统画像」是对**被扫描目标服务**的系统级视图,把散落的信息聚成一份可读画像,给安全测试/渗透打底。**五维**:系统框架 / 暴露面 / 技术流程 / 渗透视角 / 风险点,外加一段 AI 叙述。

关键原则:**引用不复制**。暴露面只给接口 id、风险/渗透只给 finding id,**明细一律跳已有的接口详情页 / finding 详情页**,画像本身不复制接口行或 finding 行。

画像是**每服务**的,挂在**服务详情页的一个 Tab**(不进侧边栏)。由后端在扫描末尾自动生成,前端只做展示 + 触发「重新生成」。

---

## 1. 接口

### 1.1 取画像 —— `GET /api/v1/security/services/{name}/system-profile`

Query:`sha`(可选,省略=最新)、`project`(可选,当前项目)。
- **200** → 下面的 `SystemProfile` 对象。
- **404** → 该服务**尚未生成画像**(没扫过 / 关了开关)。前端应显示空态「尚无系统画像,请先对该服务完成一次扫描」,**不报错、不重试**(react-query `retry:false`)。

### 1.2 历史 —— `GET /api/v1/security/services/{name}/system-profile/history`

Query:`project`。返回 `{ "items": [{ "sha", "generator_version", "generated_at" }] }`(新→旧)。用于 sha 切换下拉(可选,MVP 可不做)。

### 1.3 重新生成 —— `POST /api/v1/security/services/{name}/system-profile/regenerate`

Query:`project`。刷新最新画像的聚合 + AI 叙述(免拉源码,几秒内返回新的 `SystemProfile`)。
- **200** → 新 `SystemProfile`。成功后 invalidate 画像查询 + toast「已重新生成」。
- **404** → 从未画像过(先扫描)。

| | `narrative` | markdown / `whitespace-pre-wrap` 文本块 |

## 3. UI 结构

挂载点:**服务详情页新增一个 Tab「系统画像」**(与「接口」「业务知识」等 Tab 并列)。数据源 `useSystemProfile(serviceName)`,按当前项目隔离。

系统画像 Tab:
┌──────────────────────────────────────────────┐
│ <sha前12> · 生成于 <time> · <model>   [重新生成 ⟳] │  头部
├──────────────────────────────────────────────┤

## 约束(务必遵守)

1. **引用不复制**:surface/risks/recon 里的 `*_interface_ids` / `*finding_ids` 只是引用,**明细一律跳已有的接口详情页 / finding 详情页**,画像页不重新拉、不复制接口/finding 列表。
2. **404 = 尚未生成**,不是错误:显示空态「请先对该服务完成一次扫描」,`retry:false`,不报红。
3. **`recon.not_derivable_from_code` 必须展示**:这是诚实性要求——外部可达性、运行时鉴权是否真正挂载,代码侧判不了,得明确告诉用户留给主机侧,**不能省略、不能伪造成"安全"**。
4. **画像是 per-service**:挂服务详情 Tab,**不进侧边栏**,不做独立顶层页。
5. **按当前项目隔离**:所有请求带 `project` = 当前选中项目。
6. **列表来自后端**:五维内容全部来自 `system-profile` 响应,**禁止前端硬编码**任何维度项;后端加字段前端自然多展示。
7. **重新生成**:`POST .../regenerate` → 成功 invalidate 画像查询 + toast;pending 时按钮转圈禁用。

## 复用(与本控制台已有一致)

- 徽章:严重度 `SeverityBadge`、风险 `RiskBadge`(P0/P1/P2)、方法 `MethodBadge`。
- 卡片/空态:`SectionCard` / `EmptyBlock` / `LoadingBlock`。
- 跳转:接口详情 `/security/interfaces/$id`、finding 详情 `/security/findings/$id`。
- 扫描进度条已加 `system_profile` 阶段(`theme.STAGE_ORDER` / `STAGE_META`),实时进度会显示「系统画像」。
