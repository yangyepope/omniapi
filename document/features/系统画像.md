# 系统画像(前端对接)

- **创建日期**: 2026-07-11
- **状态**: 已上线
- **关联变更**: [FEAT-014](../changelog/FEAT-014-系统画像前端对接.md)(配套 gitlab-scanner FEAT-029)

> 平台侧只做**代理 + 展示**;画像的生成、存储、四维聚合逻辑都在下游 gitlab-scanner。

## 需求背景

为被扫描目标系统提供系统级视图(框架 / 技术流程 / 暴露面 / 风险点 + AI 叙述),
作为服务详情页的一个 Tab,帮助安全工程师快速理解陌生服务。

## 数据结构 · 数据库设计

无平台侧 DB 变更。画像存于 scanner 的 `service_system_profiles` 表,平台只透传。

## 配置项

无平台侧新增配置(下游 scanner 有 `SYSTEM_PROFILE_ENABLED` / `SYSTEM_PROFILE_MODEL`)。

## 接口列表

平台代理(JWT,`/api/v1/security/*`),透传到 scanner `/api/admin/*`:

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/security/services/{name}/system-profile?sha=&project=` | 最新或指定 sha 画像;无则 404 |
| GET | `/security/services/{name}/system-profile/history` | 已画像 sha 列表 |
| POST | `/security/services/{name}/system-profile/regenerate` | 免源码刷新最新画像 |

## 前端

- `security/api.ts`:`SystemProfile` 类型族 + 3 方法。
- `security/hooks.ts`:`useSystemProfile` / `useSystemProfileHistory`(按当前项目隔离;
  404 不重试)。
- `security/SystemProfilePanel.tsx`:四维卡片 + AI 叙述 + 重新生成;风险 top 项链到
  finding 详情;暴露面/风险为聚合与引用,明细按 id 走已有端点下钻。
- `routes/_layout/security/services/$name.tsx`:「系统画像」Tab。
- `components/security/theme.ts`:进度条补 `system_profile` 阶段。

## 失败降级

- 服务从未画像 → 后端 404 → 面板显示"尚无系统画像,请先扫描"(不报错、不重试)。
- 下游 AI 未配置 → 画像 narrative 为降级文案,四维确定性数据照常展示。
