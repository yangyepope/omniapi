# 实施方案 - 还原 UI 中文显示

根据项目语言规范（[01-工作流与语言规范](file:///root/security-platform/.agent/rule/01-%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%B8%8E%E8%AF%AD%E8%A8%80%E8%A7%84%E8%8C%83.md)），在 UI 重构过程中意外引入的英文标签需全部替换回**简体中文**。本次调整涵盖“服务管理”列表与“系统设置”所有模块，确保不保留任何英文括号或注释性单词。

## 用户审核项

> [!IMPORTANT]
> 所有的状态标识（如 Healthy, Risk）和导航标签（如 Explore）将严格还原为中文。如果某些专有名词（如 API Key）在原始代码中是英文且用户未要求修改，则保持现状；否则，所有 UI 展示文字均转为中文。
