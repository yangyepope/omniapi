# Internal Database Connection Fix & E2E Verification

The `prestart` and `backend` services are failing to connect to the database because they are trying to use the external host port (5332) instead of the internal container port (5432).

## User Review Required

> [!IMPORTANT]
> - We will hardcode `POSTGRES_PORT=5432` for internal service communication in `compose.yml` and `compose.override.yml`.
> - This does NOT change the external port (5332) used to access the DB from the host.

## Proposed Changes

### [Docker Stack]

#### [MODIFY] [compose.yml](file:///root/omniapi/compose.yml)
- Change `POSTGRES_PORT` from `${POSTGRES_PORT}` to `5432` for `prestart` and `backend` environment variables.

#### [MODIFY] [compose.override.yml](file:///root/omniapi/compose.override.yml)
- Ensure all internal service dependencies (like `celery-worker`) use `POSTGRES_PORT=5432`.

### [Verification]

#### [RUN] `docker compose up -d db redis backend mailcatcher proxy`
Restarting only essential services to verify the fix.

#### [RUN] `bunx playwright test tests/verify-login.spec.ts`
Running the login verification test.
