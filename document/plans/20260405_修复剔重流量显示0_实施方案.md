# 修复接口详情中“剔重后流量”显示 0 的问题

## 问题描述
在接口详情页中，指标卡片显示“原始总流量”为正确数值（如 124），但“剔重后流量”显示为 0。
- **现状**: 后端 `get_module_endpoint_detail` 接口实时从 `FilteredFlow` 表通过 `count()` 和 `sum()` 聚合统计。
- **异常原因猜想**:
    - 在某些数据库方言中 `func.count()` 语法在 SQLModel 下产生非预期结果。
    - 实时计算逻辑与 `ApiEndpoint` 表中的持久化统计字段逻辑冲突或未对齐。
    - 针对某些旧接口，`FilteredFlow` 为空但总流量记录在接口元数据中。

## 提议变更

### 1. 后端逻辑加固 [backend]
#### [修改] [system_modules.py](file:///root/omniapi/backend/app/api/routes/system_modules.py)
- **优化统计查询**: 使用更明确的 `func.count(FilteredFlow.id)` 代替 `func.count()`。
- **引入持久化字段兜底**: 
    - 优先使用从 `FilteredFlow` 表实时统计出的数值（因为其包含最新的变体样本信息）。
    - 若实时统计出的 `dedup_traffic_count` 为 0，但 `ApiEndpoint` 表自身的 `unique_traffic_count` 字段不为 0，则使用表字段作为降级方案展示。
    - 同样逻辑应用于 `total_traffic_count`。
